## 1. 일배치 시스템 아키텍처 개요

시스템은 **어댑터 패턴(Adapter Pattern)**을 적용하여 외부 데이터 소스가 바뀌더라도 내부 비즈니스 로직과 DB 구조에 영향을 주지 않도록 격리합니다.

```
                  [NestJS Scheduler (@Cron '0 2 * * *')]
                                    │
                                    ▼
                     ┌────────────────────────────┐
                     │   BatchOrchestratorService  │
                     └──────────────┬─────────────┘
                                    │ 소스별 순차/병렬 수집 트리거
        ┌───────────────────────────┼──────────────────────────┐
        ▼                           ▼                          ▼
┌──────────────────┐      ┌──────────────────┐       ┌──────────────────┐
│ OnbidAdapter     │      │ MolitPriceAdapter│       │ CourtAuction     │
│ (온비드 공매 API) │      │ (국토부 실거래가) │       │ (추상화 어댑터)  │
└────────┬─────────┘      └────────┬─────────┘       └────────┬─────────┘
         │                         │                          │
         └─────────────────────────┼──────────────────────────┘
                                   │ Raw JSON 응답 저장
                                   ▼
                   ┌───────────────────────────────┐
                   │ raw_external_payloads 테이블  │
                   └───────────────┬───────────────┘
                                   │
                                   ▼ (파싱 & 검증 Worker)
                   ┌───────────────────────────────┐
                   │ KakaoGeocodingService         │
                   │ (주소 -> WGS84 위경도 변환)   │
                   └───────────────┬───────────────┘
                                   │
                                   ▼ (고유키 기준 Upsert)
                   ┌───────────────────────────────┐
                   │ 정제 테이블 반영              │
                   │ - auction_items               │
                   │ - public_auction_items        │
                   │ - molit_real_transactions     │
                   └───────────────┬───────────────┘
                                   │
                                   ▼ (통계 집계 파이프라인)
                   ┌───────────────────────────────┐
                   │ PriceAnalysisCalculationBatch │
                   │ (시세분석 & 저평가율 갱신)     │
                   └───────────────────────────────┘
```

## 2. 어댑터 추상 인터페이스 정의 (TypeScript)

외부 데이터 소스가 변경되거나 새 제공자가 추가되어도 공통 인터페이스를 따르도록 구현합니다.

```typescript
// src/batch/interfaces/data-fetcher.interface.ts

export interface RawFetchResult<T = any> {
  sourceType: 'ONBID' | 'COURT_AUCTION' | 'MOLIT_PRICE';
  externalItemId: string; // 온비드 관리번호, 법원 사건번호, 또는 거래고유키
  payload: T;
}

export interface IExternalDataFetcher {
  readonly sourceType: 'ONBID' | 'COURT_AUCTION' | 'MOLIT_PRICE';
  
  /**
   * 지정된 조건(예: 날짜 범위, 지역 코드 등)으로 원천 데이터를 수집
   */
  fetchDailyBatch(batchRunId: string, params?: Record<string, any>): Promise<RawFetchResult[]>;
}
```

## 3. 핵심 어댑터 구현 전략

### 3.1 온비드 공매 어댑터 (OnbidAdapter)
- **제공처:** 공공데이터포털 캠코 온비드 물건 정보 Open API
- **수집 주기:** 매일 새벽 02:00 (전일 공고 및 변경 물건)
- **주요 파라미터:** `pageNo`, `numOfRows`, `searchStartDate`, `searchEndDate`

### 3.2 국토교통부 실거래가 어댑터 (MolitPriceAdapter)
- **제공처:** 공공데이터포털 국토교통부 아파트/연립다세대 매매 실거래가 API
- **수집 주기:** 매일 새벽 03:00 (전월 및 당월 신고 거래 내역)
- **주요 파라미터:** `LAWD_CD` (시군구 5자리 코드), `DEAL_YMD` (거래년월 YYYYMM)

### 3.3 법원경매 어댑터 (CourtAuctionAdapter - 추상화/Mock 지원)
- **제공처:** MVP 단계에서는 유료 데이터 API 스펙 계약을 전제로 한 **모의(Mock) 어댑터 및 추상화 구현체** 탑재
- **전환 용이성:** 정식 B2B 계약 체결 시 `CourtAuctionLiveApiAdapter`로 클래스만 교체하면 즉시 상용 전환 가능

### 3.4 카카오 로컬 지오코딩 서비스 (KakaoGeocodingService)
- 주소 텍스트(`address_jibun` 또는 `address_road`)를 받아 위도/경도를 조회
- 일일 쿼터 제한(일 30만 건)을 방어하기 위해 **이미 좌표가 존재하는 물건은 재요청하지 않는 캐싱 로직** 포함

## 4. 재시도 메커니즘 및 지수 백오프 (Exponential Backoff)

외부 공공 API의 간헐적 타임아웃이나 503 오류에 대비하여 공통 재시도 유틸리티를 적용합니다.

```typescript
// src/batch/utils/retry.util.ts

export async function withExponentialBackoff<T>(
  operation: () => Promise<T>,
  maxRetries: number = 3,
  initialDelayMs: number = 1000,
): Promise<T> {
  let attempt = 0;
  while (attempt < maxRetries) {
    try {
      return await operation();
    } catch (error) {
      attempt++;
      if (attempt >= maxRetries) {
        throw new Error(`[Batch Failed] 최대 재시도 횟수(${maxRetries}) 초과: ${error.message}`);
      }
      const delay = initialDelayMs * Math.pow(2, attempt);
      console.warn(`[Batch Retry] ${attempt}/${maxRetries} 실패. ${delay}ms 후 재시도...`);
      await new Promise((resolve) => setTimeout(resolve, delay));
    }
  }
  throw new Error('예외 상황 발생');
}
```

## 5. 일배치 스케줄러 오케스트레이터 (NestJS ScheduleModule)

```typescript
// src/batch/batch-orchestrator.service.ts

import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { v4 as uuidv4 } from 'uuid';

@Injectable()
export class BatchOrchestratorService {
  private readonly logger = new Logger(BatchOrchestratorService.name);

  constructor(
    private readonly onbidAdapter: OnbidAdapter,
    private readonly courtAuctionAdapter: CourtAuctionAdapter,
    private readonly molitAdapter: MolitPriceAdapter,
    private readonly rawPayloadRepo: RawExternalPayloadRepository,
    private readonly syncProcessor: SyncProcessorService,
  ) {}

  /**
   * 매일 새벽 02:30 일배치 실행
   */
  @Cron('30 2 * * *')
  async handleDailySync() {
    const batchRunId = `batch_${new Date().toISOString().slice(0, 10)}_${uuidv4().slice(0, 8)}`;
    this.logger.log(`========== [일배치 시작] Run ID: ${batchRunId} ==========`);

    try {
      // 1. 공매(온비드) 데이터 수집 및 Raw 저장
      this.logger.log('[1/4] 온비드 데이터 수집 중...');
      const onbidItems = await this.onbidAdapter.fetchDailyBatch(batchRunId);
      await this.rawPayloadRepo.saveBatch(onbidItems, batchRunId);

      // 2. 법원경매 데이터 수집 및 Raw 저장
      this.logger.log('[2/4] 법원경매 데이터 수집 중...');
      const courtItems = await this.courtAuctionAdapter.fetchDailyBatch(batchRunId);
      await this.rawPayloadRepo.saveBatch(courtItems, batchRunId);

      // 3. 국토부 실거래가 수집 및 Raw 저장
      this.logger.log('[3/4] 국토부 실거래가 데이터 수집 중...');
      const molitItems = await this.molitAdapter.fetchDailyBatch(batchRunId);
      await this.rawPayloadRepo.saveBatch(molitItems, batchRunId);

      // 4. Raw 데이터를 정제 테이블로 변환 (지오코딩 & Upsert)
      this.logger.log('[4/4] 정제 테이블 반영 및 PostGIS 좌표 변환 실행...');
      await this.syncProcessor.processPendingRawPayloads(batchRunId);

      this.logger.log(`========== [일배치 완료] Run ID: ${batchRunId} ==========`);
    } catch (error) {
      this.logger.error(`[일배치 치명적 오류 발생] ${error.message}`, error.stack);
      // 향후 Slack 웹훅 또는 관리자 이메일 알림 연동
    }
  }
}
```
